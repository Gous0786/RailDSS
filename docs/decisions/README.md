# Decision records

Numbered records of project decisions that the specification leaves open (spec §15 OD-xx) or that
need a recorded review (for example licences, C-07). One file per decision: `NNNN-short-title.md`.

A record states its context, the options considered, the decision with its conditions, and the
consequences. Its status is **Proposed** until the project owner accepts it by merging the PR that adds
it. A later record that changes a decision supersedes the earlier one, which is then not edited
except for its status line.
